# 课程复习计划本

一个纯本地的课程复习计划应用（Vue 3 + TypeScript + Vite）。学生录入课程、考试日期、章节与熟练度后，应用按剩余天数自动分配每日复习量；临时缺席登记后，未完成章节自动顺延重排，已完成记录始终保留。无需在线账号，数据保存在浏览器 localStorage。

## 功能

- **课程与章节管理**：添加课程（名称 + 考试日期），为每门课录入章节和熟练度（1 陌生 – 5 熟练），章节以卡片展示，可标记完成/未完成或删除。
- **每日复习计划**：从今天到考试日，按章节权重（熟练度越低权重越高）把未完成章节均匀摊到每一天；熟练度低的章节优先排前。
- **缺席重排**：登记缺席日期后，该日不安排复习，未完成章节自动顺延到后续日期；已完成章节的完成日期记录保留，不再参与排期。
- **进度图**：每门课程按权重计算完成百分比，附总进度条（SVG 展示）。
- **周计划打印**：以周一为起点展示本周七天的复习安排，点击「打印本周计划」输出只含周计划的打印页。

## 环境要求

- Node.js 24.15.x（兼容 20.19+ / 22.12+）
- 仅使用 npm

## 安装与启动

```bash
npm install        # 或 npm ci
npm run dev        # 开发服务器，默认 http://localhost:5173
```

按 run-local.json 清单方式启动（绑定本机、固定端口）：

```bash
npm run dev -- --host 127.0.0.1 --port {port} --strictPort
```

浏览器打开 `http://127.0.0.1:{port}/` 即可使用，演示全程离线。

## 测试与构建

```bash
npm test           # vitest 单次运行核心排期逻辑测试
npm run build      # vue-tsc 类型检查 + vite 生产构建
npm run preview    # 预览生产构建
```

## 核心逻辑

排期逻辑在 `src/lib/scheduler.ts`，为纯函数：

- `planCourse(course, today, absentDates)`：单门课程的每日分配。可安排日为今天到考试日（含）剔除缺席日；已完成章节不参与；按权重（6 − 熟练度）贪心分摊到各天。
- `buildSchedule(courses, today, absentDates)`：合并多门课程，按日期升序输出。
- `courseProgress(course)`：按权重计算完成百分比。

计划是派生数据而非存储数据：每次由课程、缺席日和当前日期重新计算，因此标记缺席或完成后自动重排，完成记录（`completedAt`）保存在课程数据中不会丢失。

测试见 `src/lib/scheduler.test.ts`，覆盖日期工具、每日分配、熟练度权重、缺席顺延、完成记录保留和进度计算。

## 数据存储

所有数据保存在浏览器 localStorage（键 `course-review-planner:v1`），不上传任何服务器，清除浏览器数据会删除记录。
