# 宠物照护交接板

多人协作照看宠物的本地演示应用。家庭成员或室友可以围绕喂食、遛狗、清洁、用药四类事项分工：谁在什么时间完成了哪件事、留下了什么备注，都记录在交接板上，避免“以为对方喂过了”或“重复喂了两顿”。

## 功能

- **事项安排**：按宠物安排喂食、遛狗、清洁、用药提醒（日期 + 时间 + 说明），也可临时添加新事项。
- **完成确认**：确认时记录完成时间、执行人和备注，数据保存在浏览器 localStorage。
- **重复确认提示**：同一事项被再次确认时弹出醒目警告，确认后追加一条标记为「重复确认」的交接记录，并在列表和导出中体现。
- **按日期查看**：前一天 / 后一天 / 日期选择器切换，默认只显示未完成任务，可切换查看全部。
- **交接记录导出**：当日或全部记录可导出为 CSV（带 BOM，Excel 可直接打开）或 JSON。
- **示例数据**：首次启动自动载入虚构宠物（橘猫「布丁」、柯基「豆豆」、垂耳兔「雪球」）和三位照护人的演示数据，含一条重复确认示例；页头可一键重置。

## 技术栈

Svelte 5 + TypeScript + Vite，测试使用 Vitest。纯前端应用，无后端、无外部账号或收费服务，离线可用。

## 环境要求

- Node.js 24.15.x（兼容 20.19+ / 22.12+）
- 仅使用 npm

## 安装

```bash
npm install    # 或 npm ci
```

## 启动（开发）

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

浏览器打开 http://127.0.0.1:5173/ 即可。端口被占用时命令会直接失败，请更换 `--port` 参数或释放端口。

## 测试与构建

```bash
npm test        # Vitest 单次运行核心逻辑测试
npm run check   # svelte-check 类型检查
npm run build   # 产出到 dist/
npm run preview # 预览构建产物
```

## 目录结构

- `src/lib/logic.ts` — 纯函数核心逻辑：完成确认与重复检测、按日期过滤、CSV/JSON 导出行生成
- `src/lib/logic.test.ts` — 核心逻辑测试
- `src/lib/store.ts` — Svelte store 与 localStorage 持久化
- `src/lib/sampleData.ts` — 虚构宠物示例数据
- `src/components/` — 任务卡片、确认弹窗、添加事项、交接记录等界面组件
- `run-local.json` — 本地启动清单（`npm run dev` 入口）
