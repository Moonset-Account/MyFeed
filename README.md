# 宠物照护交接板

多人协作照看宠物的本地 Web 应用。按日期查看每日照护事项（喂食、遛狗、清洁、用药），
完成时记录完成时间、执行人和备注；同一事项被重复确认时会给出醒目提示，避免重复喂药、
重复喂食。全部交接记录可导出为 CSV 或 JSON，方便换班时交接。

示例数据（宠物「布丁 / 可乐 / 雪球」与照护人「小林 / 阿梅 / 老周 / 阿凯」）均为虚构。
数据保存在浏览器 localStorage，完全离线可用，不接入任何外部账号或收费服务。

## 功能

- **按日期查看事项**：前一天 / 后一天 / 日期选择器切换，显示「未完成 x / 共 y 项」，可勾选「只看未完成」。
- **确认完成**：选择执行人、填写备注，完成时间自动记录为当前时间。
- **重复确认提示**：同一事项当天已有完成记录时，弹窗显示上次执行人与时间并二次确认；
  仍记录则该条标记为「重复确认」，在列表和交接记录中以醒目样式区分。
- **交接记录导出**：一键导出 CSV（带 BOM，Excel 可直接打开）或 JSON。
- **重置示例数据**：清空本地记录并恢复内置演示数据。

## 环境要求

- Node.js 24.15.x（兼容 24.x），仅使用 npm。

## 安装与启动

```bash
npm ci          # 或 npm install，安装全部依赖
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

浏览器打开 http://127.0.0.1:5173/ 即可使用。端口被占用时 dev 服务器会直接报错退出，
不会自动换端口。

## 测试与构建

```bash
npm test        # Vitest 单次运行核心逻辑测试（日期工具、实例生成、重复确认、导出等）
npm run build   # 产出 dist/ 静态文件
npm run preview # 预览构建产物
```

## 目录结构

```
src/
  App.svelte                 页面：日期导航、事项列表、交接记录与导出
  lib/
    types.ts                 宠物 / 事项模板 / 完成记录类型
    careLogic.ts             核心逻辑：实例生成、重复确认判定、CSV/JSON 导出（纯函数，可测试）
    careLogic.test.ts        核心逻辑测试
    sampleData.ts            虚构宠物、照护人与每日事项模板、演示用历史记录
    state.svelte.ts          响应式状态与 localStorage 持久化
    components/
      TaskCard.svelte        单个事项卡片（状态、完成记录、确认按钮）
      CompleteDialog.svelte  确认完成弹窗（含重复确认提示）
run-local.json               本地启动清单（web 服务：npm run dev）
```
