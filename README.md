# 出租房交接检查表

本机离线使用的出租房交接检查工具（Vue 3 + TypeScript + Vite，纯前端，无后端、无外部账号或收费服务）。

## 功能

- 按房间记录：设施状态（完好 / 损坏 / 缺失）与备注、照片说明、钥匙数量、水表与电表读数。
- 入住检查与退租检查两次录入，「对比与交接单」页逐项对比并高亮变化项。
- 任一次检查存在缺项（设施状态、钥匙数量、水电表读数、检查日期、双方签字姓名未填）时，禁止生成完成版交接单，并列出全部缺项。
- 双方签字姓名录入；生成完成版交接单后可打印（打印视图只输出交接单正文）。
- 本地 JSON 备份：一键导出 / 导入备份文件；填写内容同时自动保存在浏览器 localStorage。
- 房间与设施可自定义增删（默认带客厅、主卧、厨房、卫生间示例）。

## 环境要求

- Node.js 24.15.x（兼容 24.x），仅使用 npm。

## 安装

```bash
npm install
```

## 启动（开发）

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

浏览器打开 http://127.0.0.1:5173/ 。端口被占用时命令会直接失败，请更换端口或释放端口后重试。

## 测试

```bash
npm test
```

对核心业务逻辑（完整性校验、缺项拦截、逐项对比、JSON 备份导入导出）做单次运行的单元测试。

## 构建

```bash
npm run build
```

## 数据说明

所有数据仅保存在本机浏览器中（localStorage），不会上传到任何服务器。更换浏览器或清除站点数据前，请先使用「导出 JSON 备份」保存数据。
