# 多人旅行打包清单

一个纯前端、可离线使用的多人旅行打包工具（Vue 3 + TypeScript + Vite）。

## 功能

- **按目的地与行程天数建清单**：新建行程时填写目的地与天数，自动生成建议物品——衣物数量随天数增加，目的地命中关键词（海边、滑雪、徒步、露营、商务、亲子等）时追加对应装备。
- **分配携带人并标记已打包**：每件物品可指派给一名成员，勾选即标记已打包，顶部实时显示整体进度。
- **共享物品唯一负责人**：共享物品（如药箱、帐篷）全员共用，但只能指定一名负责人，重新指派会替换原负责人；未指定负责人时给出提醒。
- **超重提醒**：每名成员有行李箱预设限重（kg，可调），其名下物品总重超过限重时，负重条变红并在顶部横幅提醒。
- **按人筛选**：物品清单支持按 全部 / 未分配 / 指定成员 筛选。
- **复用历史清单**：历史行程可一键复制为新一轮清单，携带人关系保留、打包进度清零。
- **打印**：行程页提供打印按钮，输出按携带人分组、带勾选框的纸质清单。
- **刷新保留进度**：全部数据通过 localStorage 持久化（防抖写入），刷新或关闭页面后进度不丢失。

## 环境要求

- Node.js 24.15.x（兼容 20.19+ / 22.12+）
- 仅使用 npm；安装依赖时需要联网，运行与演示完全离线，不接入外部账号或收费服务。

## 安装

```bash
npm ci
```

## 启动

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

然后访问 http://127.0.0.1:5173/ 。端口被占用时命令会直接失败（`--strictPort`），不会自动换端口。

本目录的 `run-local.json` 是本地启动清单，与上述命令一致，其中 `{port}` 由启动者替换为实际端口。

## 测试

```bash
npm test
```

使用 Vitest 单次运行（不进入监听模式），覆盖核心逻辑：负重与超重判定、共享物品唯一负责人、按人筛选、打包进度、历史清单复用、按目的地与天数生成物品等（`src/lib/*.test.ts`）。

## 构建

```bash
npm run build
```

先 `vue-tsc --noEmit` 做类型检查，再用 Vite 产出 `dist/`。

## 数据说明

所有行程数据保存在浏览器 localStorage（键：`trip-packing-state-v1`），不上传任何服务器；清除浏览器站点数据会重置应用。
