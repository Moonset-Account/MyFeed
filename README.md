# 阳台植物养护日历

一个使用 Svelte、TypeScript 和 Vite 构建的本地离线 Web 应用。它帮助记录阳台植物的浇水间隔、光照位置、施肥与换盆历史，并根据最近一次“实际养护日期”生成本地提醒列表。

## 功能

- 为每盆植物记录名称、品种、光照位置、浇水间隔、可选施肥间隔、可选换盆间隔和备注。
- 根据建档日期或最近一次实际养护日期自动计算浇水、施肥、换盆待办。
- 本地提醒列表按逾期、今天、未来待办排序。
- 连续阴雨时可手动将浇水提醒顺延 1 到 30 天，可多次顺延并叠加。
- 顺延是独立记录，不会写入“已浇水”；只有点击“已实际浇水”才会结清顺延并开启下一周期。
- 支持补录今天以前的养护日期；补录早于顺延发生日的浇水不会错误结清未来顺延。
- 支持照片占位，也可以选择本机图片；图片以 data URL 形式保存在浏览器记录中，不访问网络。
- 支持将全部植物和养护记录导出为 JSON 备份，并可再次导入恢复。
- 不接入外部账号、收费服务或在线 API。

## 环境要求

- Node.js 24.15.x
- npm 11.x
- 仅安装依赖时需要网络；安装完成后，开发和演示均在本机运行。

## 安装

在项目根目录执行：

```bash
npm ci
```

如果本机全局 npm 缓存存在历史权限问题，项目已在 `.npmrc` 中指定项目内缓存目录 `.npm-cache/`，不会修改全局目录。

## 本地启动

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

启动后访问：

```text
http://127.0.0.1:5173/
```

`run-local.json` 已使用同一组参数，并通过 `{port}` 注入启动者分配的端口。端口被占用时 Vite 会因 `--strictPort` 直接失败，不会自动换端口。

## 构建与测试

生产构建会先执行 Svelte/TypeScript 检查，再生成 `dist/`：

```bash
npm run build
```

运行一次核心逻辑测试：

```bash
npm test
```

测试覆盖日期计算、待办排序、阴雨顺延叠加、实际浇水结清顺延、补录边界、植物删除和 JSON 备份校验。

## 使用说明

1. 点击“添加植物”，填写浇水间隔；施肥和换盆间隔可以留空，留空后不会生成对应待办。
2. 新建植物时可填写最近一次实际浇水、施肥或换盆日期；留空时从建档日期开始排期。
3. 在顶部选择本次记录日期，可直接在提醒列表中标记实际养护，或进入植物详情补录。
4. 遇连续阴雨时，在浇水待办上点击“阴雨顺延”，填写天数和原因。待办日期会后移，历史中仍显示“待实际浇水”。
5. 植物详情中可以查看完整浇水、施肥、换盆和顺延历史。
6. 定期点击“导出备份”保存 JSON 文件；导入备份会校验结构并替换当前浏览器中的记录。

## 数据存储

所有数据保存在当前浏览器的 `localStorage` 中，键名为：

```text
balcony-plant-care-calendar:v1
```

照片嵌入备份 JSON，因此单张图片限制为 5 MB，避免本地备份过大。更换浏览器、清理浏览器数据或更换电脑前，请先导出备份。
