# 露营装备检查册

一个完全本地运行的露营装备管理应用，使用 Svelte、TypeScript 和 Vite 构建。应用不需要账号、服务器数据库或收费服务；数据保存在当前浏览器的 `localStorage` 中。生产构建内置 Service Worker，首次在线或本地打开后会缓存应用外壳，之后可断网打开。

## 功能

- 维护帐篷、炉具、照明、睡眠、炊具和工具等装备的拥有数量。
- 分别记录损坏件数；电池类装备可记录未充电件数。
- 新建出行行程，按装备分配数量和需要已充电的数量。
- 出发前提示缺件、会被带上的损坏件，以及未充电电池。
- 确认出发后从家中库存扣除装备，避免重复分配。
- 归来时对照出发清单逐项勾选，记录归还数、缺件、新损坏和未充电。
- 将常用分配保存为行程模板，并在新行程中一键载入。
- 自动保存维修待办；标记修好后同步减少库存损坏数。
- 内置“周末过夜”演示模板和示例库存，可一键恢复。

## 环境要求

- Node.js 24.15.x
- npm 11.x
- 不需要 Docker、外部账号或外部 API。

## 安装

```bash
npm install
```

如果本机 npm 全局缓存目录提示 root-owned 文件权限问题，可在项目内使用独立缓存，不会改动用户目录：

```bash
npm install --cache .npm-cache
```

`.npm-cache/` 已在 `.gitignore` 中排除。

## 本地开发

根目录 `run-local.json` 已声明启动命令。手动启动可运行：

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

然后打开：

```text
http://127.0.0.1:5173/
```

端口被占用时 Vite 会按 `--strictPort` 直接失败，不会自动换端口或脱离启动进程。

## 生产构建与预览

```bash
npm run build
npm run preview -- --port 4173
```

Service Worker 只在生产构建中注册。用预览服务器打开一次后，停止网络并刷新页面，可验证应用外壳仍可加载。

## 测试

```bash
npm test
```

测试使用 Vitest 单次运行，覆盖装备数量规范化、出发缺件/损坏/未充电提示、出发扣库存、逐项归还回补库存，以及损坏件维修待办生成等核心逻辑。

## 数据与隐私

- 所有行程、库存、模板和维修待办仅保存在当前浏览器的 `localStorage`。
- 清除浏览器站点数据会删除记录；页面中的“恢复演示数据”也会覆盖当前记录。
- 应用不提交媒体文件，不包含数据库运行文件、凭据或本机绝对路径。
