# 无障碍检查清单（家居改造顾问）

面向家居改造顾问的本地离线工具：按区域记录无障碍测量数据、登记问题与整改建议、跟踪整改前后照片，并生成按区域汇总的打印报告。

## 功能

- **区域测量**：预置玄关、客厅、走廊、卫生间、卧室、厨房、阳台，可增删区域；记录门净宽、通道净宽、台阶/门槛高度与备注，不达标项按当前阈值自动标红。
- **问题与整改**：登记问题（描述、严重程度、整改建议），同一问题可勾选关联多个区域；问题照片现场勾选上传（自动压缩后存本机）；整改完成后标记状态并补录整改后照片，前后记录均保留。
- **区域汇总**：各区域测量达标情况与待整改/已整改问题一览，总体统计按问题去重。
- **打印报告**：一键生成含阈值说明、测量表、问题清单与前后对比照片的报告，可打印或导出 PDF。
- **阈值设置**：门净宽、通道净宽、台阶高度限值均可手动配置，保存后即时生效。

所有数据保存在浏览器 localStorage，不接入外部账号或收费服务，离线可用。

## 环境要求

- Node.js 24.15.x（兼容 Node 18+），仅使用 npm。

## 安装

```bash
npm install
```

## 启动（开发）

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

浏览器打开 http://127.0.0.1:5173/ 。根目录 `run-local.json` 为本启动清单，`{port}` 由启动者替换。

## 测试

```bash
npm test
```

单次运行核心逻辑测试（阈值判定、按区域汇总、多区域关联去重、阈值校验），不进入监听模式。

## 构建

```bash
npm run build
```

产物输出到 `dist/`。

## 目录结构

- `src/logic/rules.ts` — 阈值判定与汇总核心逻辑
- `src/logic/store.ts` — localStorage 持久化与照片压缩
- `src/components/` — 区域测量、问题整改、汇总、报告、设置五个视图
- `src/__tests__/rules.test.ts` — 核心逻辑测试
