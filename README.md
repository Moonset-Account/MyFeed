# 入职任务地图

新成员自助跟进入职事项的本地演示应用：按角色预置账号申请、设备领取、培训等任务及负责人，新人可查看任务先后依赖与完成状态；前置事项未完成时会提醒，逾期项在页面顶部集中显示。数据仅保存在浏览器 localStorage，不接入企业账号或任何外部服务。

## 功能

- 示例角色：前端工程师、后端工程师、产品经理，各含账号 / 设备 / 培训 / 团队类任务
- 每项任务带负责人、备注、截止日（按入职日期 + 偏移天数计算）和前置依赖
- 前置未完成时任务标记「待前置」，点击勾选会弹出提醒，列出需先完成的事项
- 逾期未完成项集中在顶部红色面板显示，按截止日排序
- 完成状态、角色选择与入职日期持久化在本机浏览器，可一键重置

## 环境要求

- Node.js 24.15.x（与 package-lock.json 匹配），仅使用 npm

## 安装

```bash
npm ci
```

## 启动

```bash
npm run dev -- --hostname 127.0.0.1 --port 3000
```

打开 http://127.0.0.1:3000/ 即可使用。`npm run dev` 中设置了 `WATCHPACK_POLLING=1`：本机演示环境不支持文件系统监听，轮询模式保证路由发现与热更新可用。

生产模式：

```bash
npm run build
npm start -- --hostname 127.0.0.1 --port 3000
```

## 测试

```bash
npm test
```

使用 Node 内置 test runner 单次运行，覆盖核心逻辑：依赖阻塞与提醒文案、逾期判定与逾期项汇总、拓扑排序、示例角色数据完整性（依赖有效、无环、备注与负责人齐全）。

## 目录结构

```
src/
  app/            Next.js App Router 入口（页面、布局、全局样式）
  components/     OnboardingApp 客户端组件（角色选择、任务列表、逾期面板）
  lib/
    onboarding.ts 核心逻辑：状态计算、依赖与逾期判定（纯函数，可独立测试）
    roles.ts      示例角色与任务模板
    store.ts      localStorage 持久化
tests/            核心逻辑测试（node:test）
```
