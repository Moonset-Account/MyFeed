# 课程复习计划本

一个无需账号、可离线使用的课程复习单页应用。学生可以录入课程、考试日期、章节和当前熟练度，应用会根据剩余学习日自动分配每日复习块；临时缺席时，未完成章节会重新安排到后续日期，历史完成记录会保留。

## 功能

- Vue 3、TypeScript、Vite 单页应用
- 按熟练度自动计算复习量：生疏 5 块、需巩固 4 块、基本掌握 3 块、较熟练 2 块、有把握 1 块
- 每块约 30 分钟，任务按考试日期和章节剩余量交错排期
- 今日任务、章节卡片、课程进度条和未来 7 天负荷折线图
- 添加临时缺席日后自动跳过并顺延未完成任务
- 课程清单中可直接修改考试日期（确认 / 取消）：确认后只按新的剩余天数重算未完成复习块，课程、章节、熟练度、缺席日和全部完成记录都保留，已完成内容不会重新进入计划；取消不产生任何变化
- 章节完成量以复习记录为唯一数据来源，完成与撤销同步更新章节卡片、课程统计、进度图和周计划；旧版本地数据在加载时自动迁移，撤销到最后一条记录后进度归零且可继续操作
- 完成记录保存在本机浏览器 `localStorage`，撤销记录不会误删历史
- 浏览器打印未来 7 天周计划，打印版只显示周计划内容
- 核心排期逻辑使用 Vitest 做单次测试

## 本机运行

要求使用 macOS 本机 Node.js 与 npm；依赖安装需要联网，应用运行本身不访问外部账号、数据库或收费服务。仓库内置项目级 `.npmrc`，npm 缓存使用项目内相对目录，避免受本机用户缓存权限影响。

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

启动后访问：

```text
http://127.0.0.1:5173/
```

根目录 `run-local.json` 已使用同一 Vite 命令，启动器会把 `{port}` 替换成实际端口。端口被占用时 Vite 会因 `--strictPort` 直接失败，不会切换端口。

## 测试与构建

```bash
npm test
npm run build
```

`npm test` 使用 `vitest run`，单次运行后退出；`npm run build` 先执行 TypeScript/Vue 类型检查，再生成静态文件到 `dist/`。

## 数据说明

所有课程、章节、复习记录和缺席日期都保存在当前浏览器站点的 `localStorage` 中，刷新页面不会丢失。页面提供“恢复示例数据”和“清空全部数据”。清理浏览器站点数据会删除计划本数据。
