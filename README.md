# 校园活动室预约台

基于 Vue 3 + TypeScript + Vite 的单页应用，面向校园社团的活动室预约管理。全部数据保存在浏览器 localStorage，离线可用，不依赖任何外部服务。

## 功能

- **管理配置**：管理员维护房间的容量、设备清单、每周开放时段（支持闭馆日）与每周重复的维护时段，可新增/编辑房间。
- **预约申请**：社团填写活动人数、日期与时间后提交，系统自动校验：
  - 是否在房间开放时段内
  - 是否与维护时段冲突
  - 是否超过房间容量
  - 是否与已确认的预约撞期
- **周视图**：按房间展示一周的已确认预约、维护时段与闭馆日，支持切换上一周/下一周。
- **候补与提醒**：预约被拒时可一键加入候补队列；有预约取消后，系统按提交顺序自动检查候补单，满足全部校验的候补会标记为「已提醒」，社团确认后即转为正式预约。
- **本地持久化**：房间配置、预约与候补均保存在浏览器 localStorage，刷新不丢失；「重置演示数据」可清空并恢复初始示例。

## 环境要求

- Node.js 24.x（兼容 24.15.x）
- 仅使用 npm

## 安装与启动

```bash
npm install        # 或 npm ci
npm run dev        # 开发服务器，默认 http://127.0.0.1:5173
```

按启动清单运行（替换 `{port}` 为实际端口）：

```bash
npm run dev -- --host 127.0.0.1 --port {port} --strictPort
```

浏览器访问 `http://127.0.0.1:{port}/` 即可使用。

## 构建与测试

```bash
npm run build      # 产物输出到 dist/
npm test           # vitest 单次运行核心排期逻辑测试
```

测试覆盖 `src/lib/schedule.ts` 中的纯函数：时间区间重叠判断、星期计算、开放时段/维护/超员/撞期校验，以及取消预约后候补单可转正的场景。

## 目录结构

```
src/
  lib/schedule.ts        核心排期校验逻辑（纯函数）
  lib/schedule.test.ts   核心逻辑测试
  store.ts               响应式状态 + localStorage 持久化 + 候补提升
  components/
    WeekView.vue         周视图
    BookingForm.vue      预约申请与加入候补
    BookingList.vue      已确认预约与候补队列（含提醒确认）
    AdminPanel.vue       房间容量/设备/开放时段/维护时段配置
```

## 数据说明

首次打开会写入三个示例房间和两条本周预约作为演示数据。所有数据仅存于当前浏览器的 localStorage（键 `campus-room-booking:v1`），不会上传到任何服务器。
