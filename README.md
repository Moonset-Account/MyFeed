# 家具组装步骤卡

基于 React + TypeScript + Vite 的单页应用，纯前端实现，数据保存在浏览器 localStorage，离线可用。

示例数据为虚构产品「云杉·四层书架 BS-400」。

## 功能

- **管理员配置**：在「管理员配置」页按顺序维护组装步骤（可上移/下移排序），并为整个方案配置零件清单、工具清单；每个步骤可设置配图与图片说明、本步零件用量、所需工具和检查点（可标记「必需」）。
- **逐步勾选**：用户在「组装模式」下逐步勾选检查点并完成步骤，顶部进度条实时显示完成度。
- **必需检查点拦截**：点击「完成本步骤」时若存在未勾选的必需检查点，会弹出提示列出缺漏项，步骤不会被标记完成。
- **按序执行**：尝试完成后续步骤时，若此前任一步骤仍有未勾选的必需检查点，会明确指出对应步骤与检查点并阻止完成；被拦截的步骤卡上也会显示前置提示。补齐后即可正常继续。
- **缺件暂停与补件清单**：任意步骤可「报告缺件」，登记后流程自动暂停，页面顶部生成按零件合并的补件清单；零件补齐后逐条移除记录即可恢复组装。暂停期间不能勾选检查点或完成步骤；即使管理员随后从方案中删除了被报缺的零件，补件记录仍按登记时的快照保留可读，「恢复组装」入口始终可见，恢复时保留全部已有完成进度，无需清空数据。
- **进度恢复**：方案与进度自动保存到 localStorage，刷新或重开浏览器后自动恢复；「清空进度」可重新开始。
- **步骤搜索**：按步骤标题、操作说明、图片说明、零件名称/编号、工具名称、检查点文本过滤步骤。
- **可打印材料表**：「材料表」页汇总零件清单（含各零件使用步骤）与工具清单，点击「打印材料表」通过浏览器打印，打印样式只保留材料表并附核对勾选列。

## 环境要求

- Node.js 24.15.x（兼容 Vite 8）
- 仅使用 npm；安装依赖需要联网，运行演示完全离线

## 安装与启动

```bash
npm ci          # 或 npm install，安装全部依赖
npm run dev     # 开发模式，默认 http://localhost:5173
```

按本机清单方式启动（绑定 127.0.0.1、占用失败即退出）：

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

打开浏览器访问 `http://127.0.0.1:5173/` 即可使用。

## 测试与构建

```bash
npm test        # Vitest 单次运行核心逻辑测试（检查点校验、缺件/补件清单、搜索、进度）
npm run build   # TypeScript 检查并产出 dist/
npm run preview # 预览构建产物
```

## 目录结构

```
src/
  types.ts               # 方案/步骤/零件/检查点/进度等类型
  data/samplePlan.ts     # 虚构书架示例方案
  lib/assembly.ts        # 核心逻辑：检查点校验、完成步骤、缺件与补件清单、搜索、进度
  lib/assembly.test.ts   # 核心逻辑测试
  lib/storage.ts         # localStorage 持久化（方案 + 进度恢复）
  components/            # 步骤卡、缺件面板、材料表、管理员配置、内置 SVG 插图
  App.tsx                # 应用骨架与状态编排
run-local.json           # 本地启动清单
```
