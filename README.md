# 餐厅候位叫号台

基于 Vue 3、TypeScript、Vite 的本地离线餐厅候位管理应用。应用不依赖外部账号、短信服务、数据库或收费 API，营业数据保存在当前浏览器的 `localStorage` 中。

## 功能

- 配置桌型、每桌座位数和桌数，并可新增、编辑和删除空闲桌型。
- 登记联系人、就餐人数、到店时间，以及是否接受拼桌。
- 按到店时间维护候位顺序，空桌出现时推荐能坐下的最小合适桌型。
- 叫号后预留餐桌，可确认入座、标记过号或取消。
- 双方都接受拼桌且余位足够时，推荐到已有客人入座的餐桌。
- 当前候位屏显示最新叫号、等待桌数、预计等待人数、空桌数和前几组等待客人。
- 记录登记、叫号、入座、拼桌、过号、取消、离店和当天清空操作。
- 支持一键清空当天业务数据；桌型配置保留，跨天自动开始新一天数据。

## 运行环境

- Node.js 24.15.x
- npm 11.x
- 仅需在安装依赖时联网；安装完成后可离线启动和演示。

## 安装与启动

```bash
npm ci
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

浏览器访问：

```text
http://127.0.0.1:5173/
```

根目录 `run-local.json` 已声明同样的 Vite 启动命令和就绪路径 `/`。如果端口被占用，Vite 会因 `--strictPort` 直接退出，不会自动换端口。

## 构建与测试

```bash
npm test
npm run build
```

- `npm test` 使用 Vitest 单次运行核心业务规则测试，不进入监听模式。
- `npm run build` 先执行 Vue/TypeScript 类型检查，再输出生产构建到 `dist/`。

## 业务规则说明

候位队列以到店时间升序排列；到店时间相同时按登记先后处理。系统扫描队列时，如果当前客人没有合适空桌或满足条件的拼桌桌台，会继续检查后续客人，避免前面的不可安排客人阻塞后面的客人。

直接安排优先选择“能容纳当前人数、空位数最少”的空闲桌。拼桌建议同时满足以下条件：

1. 目标桌已有客人入座。
2. 已入座客人和新客人都接受拼桌。
3. 加入后人数不超过餐桌座位数。

过号、取消和拼桌相关操作都会写入“当天记录”。过号或取消已叫号客人会释放预留餐桌；最后一组用餐客人离店后餐桌恢复空闲。

## 数据存储

应用只使用浏览器本地存储，键名为：

```text
restaurant-waitlist-state-v1
```

“当天数据清空”会清空候位、客人、日志和餐桌占用，但保留桌型配置。刷新页面不会丢失当天数据；更换浏览器或清理浏览器站点数据会清空演示数据。
