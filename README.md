# 图书修补登记册

一个基于 Vue 3、TypeScript 和 Vite 的本地离线演示应用，用于图书馆登记破损图书并跟踪修补流转。

## 功能

- 按书号登记破损位置、照片说明、修补步骤和处理人。
- 同一书号可保留多次修补记录，支持按完整或部分书号查询历史。
- 状态固定按“待评估 → 修补中 → 待上架”流转。
- “待上架”图书必须登记检查人并完成全部上架检查项，系统才会标记为“可借”。
- 首页展示待评估、修补中、待检查和可借数量，自动汇总当前待办。
- 可按当前书号关键词和状态筛选清单，并导出带 UTF-8 BOM 的 CSV 文件。
- 数据保存在浏览器 `localStorage`，不接入外部账号、收费服务、数据库或媒体上传。

## 环境要求

- Node.js 24.15.x
- npm 11.x

## 安装依赖

```bash
npm ci
```

如果本机 npm 全局缓存目录存在权限问题，可仅在本次命令中指定项目内缓存：

```bash
npm ci --cache ./.npm-cache
```

`.npm-cache/` 已在 `.gitignore` 中忽略，不应提交。

## 本地启动

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

启动后访问：

```text
http://127.0.0.1:5173/
```

根目录 `run-local.json` 使用同一个 Vite 命令，并由启动器替换 `{port}`。端口被占用时 Vite 会因 `--strictPort` 直接退出，不会自动换端口。

## 验证命令

```bash
npm test
npm run build
```

- `npm test` 使用 Vitest 单次运行核心业务规则测试，不进入监听模式。
- `npm run build` 先执行 `vue-tsc` 类型检查，再生成 `dist/`。

## 数据说明

首次打开会写入少量演示数据。页面中的“恢复演示数据”可重置示例，“清空本地数据”会删除当前浏览器中的登记记录。导出的 CSV 可由 Excel、Numbers 或表格软件打开，并对引号、换行和可能被识别为公式的内容做了转义处理。
