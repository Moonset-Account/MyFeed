# 无障碍检查清单（家居改造顾问）

面向家居改造顾问的本地单页应用：按玄关、卫生间、卧室等区域记录门净宽、通道净宽与台阶/门槛高度，登记问题照片与整改建议，整改完成后保留前后对照记录，并生成按区域汇总的可打印报告。规则阈值可手动配置。

## 功能

- **检查记录**：按区域录入门净宽、通道净宽、台阶/门槛高度与备注；超出阈值的测量项即时高亮提示。区域可自定义增删改名（默认含玄关、客厅、卫生间、卧室、厨房、阳台）。
- **问题与整改**：登记问题标题、描述、整改建议与整改前照片；同一问题可关联多个区域；整改完成后标记“已整改”并补传整改后照片，前后记录均保留。
- **汇总报告**：按区域汇总测量评估、待整改与已整改问题，一键打印（打印样式已适配，任何标签页下打印都输出报告）。
- **阈值设置**：门净宽下限、通道净宽下限、最大台阶高度均可手动配置，保存后全站评估即时生效。

数据（含压缩后的照片）仅保存在浏览器 localStorage 中，完全离线可用，不接入任何外部服务。

## 环境要求

- Node.js 24.15.x（兼容 Vite 6）
- 仅使用 npm

## 安装

```bash
npm install
```

## 启动（开发）

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

浏览器打开 http://127.0.0.1:5173/ 即可使用。根目录 `run-local.json` 为本应用的启动清单。

## 测试

```bash
npm test
```

单次运行 Vitest，覆盖阈值评估、按区域汇总（含多区域关联去重）、整改前后记录保留等核心逻辑（`src/lib/rules.test.ts`）。

## 构建

```bash
npm run build
```

## 目录结构

```
src/
  types.ts            数据模型（区域、问题、照片、阈值）
  store.ts            useReducer 状态管理 + localStorage 持久化
  lib/rules.ts        阈值评估与按区域汇总（纯函数，可测试）
  lib/storage.ts      本地存取、照片压缩为 dataURL
  components/         检查记录、问题整改、汇总报告、阈值设置界面
```
