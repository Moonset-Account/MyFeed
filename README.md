# 共读进度墙

读书会的共读写看板：组织者维护书目、章节与讨论日期，成员各自记录阅读进度，
围绕摘录汇总讨论、提出问题，并沉淀每章的讨论纪要。纯前端实现，数据保存在
浏览器 localStorage，可一键导出 / 导入本地 JSON 备份，离线可用。

## 功能

- **书目与章节（组织者）**：顶栏打开「组织者」开关后，可在左侧添加书目（书名、
  作者、章节每行一条），在章节详情中设置讨论日期、补加章节、填写讨论纪要。
- **个人进度独立**：每位成员对每章标记「未读 / 在读 / 读完」，互不影响；
  章节行内的圆点展示全体成员的进度分布，侧栏与书页头部显示个人进度条。
- **未读章节提醒**：有讨论日期且本人未读完的章节会进入提醒面板，按紧迫程度
  排序，逾期章节置顶标红；顶栏与书目列表显示待读数量。
- **摘录与讨论**：成员在章节下发布摘录（可附心得），同一段摘录下汇总所有
  成员的评论，形成讨论串。
- **提问**：每章设有提问区，供讨论前收集问题。
- **讨论纪要**：组织者按章节记录纪要，全员可见。
- **本地 JSON 备份**：顶栏「导出 JSON 备份」下载完整数据；「导入备份」校验
  后整体恢复（兼容带版本包装与裸状态两种格式）。
- **示例书目**：首次打开自动载入《人类简史》（含进度、摘录、讨论、提问、
  纪要，讨论日期相对当天生成）与《乡土中国》（章节未排期），便于直接体验。

## 环境要求

- Node.js 24.15.x，仅使用 npm。无需 Docker、外部账号或任何收费服务。

## 安装

```bash
npm install   # 或 npm ci
```

## 启动（开发）

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

然后访问 http://127.0.0.1:5173/ 。`run-local.json` 中的 `{port}` 由启动者
替换为实际端口；端口被占用时命令会直接失败（strictPort），不会自动换端口。

## 测试与构建

```bash
npm test        # vitest 单次运行：核心逻辑（提醒、进度汇总、备份解析）与 store 测试
npm run build   # tsc --noEmit 类型检查 + vite 生产构建（输出 dist/）
```

## 数据说明

- 所有数据存于浏览器 `localStorage`（键 `reading-club-state-v1`），不上传任何服务器。
- 备份文件为 JSON：`{ version, exportedAt, data }`，导入时做结构校验，成员为空或
  书目记录不完整会被拒绝。
- 清除浏览器站点数据会丢失未导出的内容，重要讨论请定期导出备份。

## 目录结构

```
src/
  types.ts            数据模型（书目/章节/成员/进度/摘录/提问）
  lib/reading.ts      纯逻辑：进度汇总、未读提醒、日期工具、JSON 备份序列化与校验
  lib/store.ts        useReducer 状态仓库与 localStorage 持久化
  lib/sample.ts       示例书目（首次启动载入）
  components/         顶栏、书目侧栏、书页视图、章节详情（摘录/提问/纪要）
run-local.json        本地启动清单（web 服务：npm run dev）
```
