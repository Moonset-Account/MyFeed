# 校园活动室预约台

面向学生社团的校园活动室预约应用。管理员维护房间容量、设备与开放时段，并登记维护时段；社团提交活动人数与时间后，系统自动检查撞期、超员、维护时段与开放时间，撞期时可登记候补，原预约取消后按提交顺序提醒候补社团转正。周视图直观展示各房间一周的预约与维护安排。

全部数据（房间配置、维护时段、预约与候补）保存在浏览器 localStorage 中，无需后端与外部账号，离线即可演示。

## 功能

- **周视图**：按房间 × 星期展示已确认预约、候补与维护时段，支持切换周；点击预约可查看详情并取消。
- **提交预约**：选择房间、日期、时间与人数后自动校验——超员、超出开放时段、维护时段冲突、与已有预约撞期都会给出明确提示；仅撞期时可一键加入候补。
- **预约与候补**：列出进行中的预约，可取消；取消已确认预约后，系统自动提醒第一个满足全部条件的候补申请，社团确认后转正。
- **管理员配置**：增删房间，编辑容量、设备与每周开放时段（每天可设多段），登记维护时段，并可一键重置演示数据。

## 环境要求

- Node.js 24.15.x（兼容 Node 20+）
- 仅使用 npm，不依赖 Docker、外部账号或收费服务

## 安装

```bash
npm install   # 或 npm ci
```

## 启动（开发）

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

浏览器打开 http://127.0.0.1:5173/ 。首次打开会写入演示数据（3 个房间、1 段维护、3 条预约），可在「管理员配置」中重置。

## 测试与构建

```bash
npm test            # vitest 单次运行核心逻辑测试（校验、候补、取消提醒）
npm run typecheck   # vue-tsc 类型检查
npm run build       # 产出 dist/
```

## 数据存储

- localStorage 键：`campus-room-booking:v1`
- 时间统一使用本地朴素 ISO 字符串（`YYYY-MM-DDTHH:mm:00`），不涉及时区换算
- 清除浏览器站点数据或在「管理员配置 → 重置演示数据」即可恢复初始状态

## 目录结构

```
src/
  lib/
    types.ts       数据模型（房间、维护时段、预约）
    datetime.ts    本地时间工具
    booking.ts     核心逻辑：预约校验、候补登记、取消后的候补提醒、转正
    seed.ts        演示数据
    storage.ts     localStorage 读写
    booking.test.ts 核心逻辑测试
  store.ts         响应式全局状态（变更自动持久化）
  components/      周视图、预约表单、预约与候补列表、管理员配置
run-local.json     本地启动清单（web 服务：npm run dev）
```
