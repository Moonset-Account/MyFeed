# 合住费用分摊本

一个基于 React、TypeScript 和 Vite 的离线合住账单工具，用于记录房租、水电、采购和其他共同开销。应用不接入支付服务、外部账号或收费 API；数据仅保存在当前浏览器的 `localStorage` 中。

## 功能

- 记录日期、类别、账单名称、金额和付款备注。
- 支持三种分摊方式：
  - 按人均：除不尽的尾差用最大余数法分配，分摊总额始终等于账单金额。
  - 固定比例：比例合计必须为 100%，金额尾差自动分配。
  - 指定金额：每个人的金额可手工填写，合计必须等于账单金额。
- 支持一人或多人实际付款，付款合计必须等于账单金额。
- 自动计算每人本月应付、已付、待支付/待收回和月结后的净差额。
- 修改账单或付款记录后，月度汇总和建议付款路径立即重新计算。
- 可标记月结并填写备注；月结后新增、修改、删除或跨月移动记录，会提示重新月结。
- 可导出当月账单 CSV 和付款记录 CSV，文件带 UTF-8 BOM，适合 Excel 打开。
- 内置示例数据，可一键恢复，方便离线演示。

## 环境要求

- Node.js 24.15.x
- npm 11.x
- macOS 本机环境，不需要 Docker、数据库或外部服务。

## 安装

在项目根目录执行：

```bash
npm ci
```

如果本机 npm 全局缓存目录存在历史权限问题，可使用项目内缓存，不影响应用运行：

```bash
npm ci --cache ./.npm-cache
```

`.npm-cache` 已在 `.gitignore` 中排除。

## 本地启动

`run-local.json` 使用以下命令启动 Vite 开发服务：

```bash
npm run dev -- --host 127.0.0.1 --port <端口> --strictPort
```

服务只绑定 `127.0.0.1`；端口被占用时会直接失败，不会自动换端口。启动后访问启动器探测的根路径 `/`。

也可以手动指定端口：

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

## 测试和构建

单次运行核心逻辑测试：

```bash
npm test
```

生产构建会先执行 TypeScript 类型检查，再生成 `dist/`：

```bash
npm run build
```

## 数据说明

应用没有后端和数据库。账单、成员、付款和月结记录保存在浏览器 `localStorage` 的 `shared-expenses-book-v1` 键下。清除浏览器站点数据或点击“恢复示例”会重置本地记录。

金额内部以“分”保存，避免 JavaScript 浮点误差。按比例或按人均分摊时，无法整除的 1 分尾差会按余数大小和稳定成员顺序分配，确保每笔账单的分摊金额、付款金额和原账单金额完全一致。

## 主要代码

- `src/core/finance.ts`：分摊、校验、月度汇总和付款路径计算。
- `src/core/csv.ts`：账单与付款记录 CSV 导出。
- `src/core/sampleData.ts`：离线演示数据。
- `src/components/BillForm.tsx`：账单录入、编辑和金额一致性检查。
- `src/components/PaymentForm.tsx`：月结付款备注。
- `src/App.tsx`：月度视图、月结状态和本地状态管理。
- `test/finance.test.ts`：核心分摊和月结计算测试。
