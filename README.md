# 捐赠物资分拣台

公益仓库的物资分拣管理应用：React + TypeScript + Vite 单页应用，纯前端实现，
数据保存在浏览器 localStorage，本机离线可用，不接入任何外部账号或收费服务。

## 功能

- **入库登记**：登记物资名称、类别、数量、单位、有效期、存放位置和备注，
  自动生成批次号；新批次默认标记为「待检查」。
- **质检标记**：在「库存总览」对待检查批次标记「合格（可发放）」或「不合格」，
  不合格批次禁止发放。
- **库存与临期提示**：按物资汇总可发放 / 待检查 / 不合格数量；
  已过期和 30 天内到期的批次在库存页顶部醒目提示。
- **物资发放**：发放数量不得超过该物资可用库存（仅统计「可发放」批次）；
  按 FEFO（先到期先出）自动分配批次，临期物资优先出库，提交前可预览出库方案。
- **批次追溯**：按批次号或物资名称搜索，查看批次从入库、质检到每次发放的完整流水。
- **记录导出**：收发记录（全部 / 入库 / 发放 / 质检）和批次库存可导出为
  带 BOM 的 CSV，Excel 可直接打开。

## 环境要求

- Node.js 24.15.x（兼容 20+），仅使用 npm。

## 安装

```bash
npm install
```

## 本地启动（开发）

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

浏览器打开 http://127.0.0.1:5173/ 。端口被占用时启动会直接失败，不会自动换端口。
首次打开仓库为空，可点击「载入示例数据」快速体验。

## 测试

```bash
npm test
```

使用 Vitest 单次运行（非监听模式），覆盖核心逻辑：入库校验、质检状态流转、
发放不超库存、FEFO 临期优先分配、临期提示、批次追溯汇总和 CSV 导出转义。

## 构建

```bash
npm run build
```

产物输出到 `dist/`（`tsc -b` 类型检查 + `vite build`）。

## 目录结构

```
src/
  lib/
    types.ts       批次与收发记录的数据模型
    inventory.ts   核心逻辑：入库、质检、发放（FEFO）、临期提示、追溯、汇总
    csv.ts         CSV 导出（转义 + BOM）
    storage.ts     localStorage 持久化
    inventory.test.ts  核心逻辑测试
  components/      入库登记、库存总览、物资发放、批次追溯、收发记录五个页面
  App.tsx          应用外壳与状态管理
  seed.ts          演示用示例数据
run-local.json     本地启动清单（web 服务：npm run dev）
```

## 数据说明

所有数据仅保存在当前浏览器的 localStorage 中，清除浏览器数据会清空记录；
导出 CSV 是留存和交接记录的方式。
