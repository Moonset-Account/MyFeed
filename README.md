# 多人旅行打包清单

一个纯前端的多人旅行打包清单应用（Vue 3 + TypeScript + Vite），数据保存在浏览器
localStorage 中，完全离线可用，不接入任何外部账号或收费服务。

## 功能

- **按目的地与行程天数建单**：新建行程时填写目的地和天数，可一键生成建议物品
  （消耗品数量随天数变化，目的地关键词如"三亚/海"会追加泳衣、防晒霜等场景物品）。
- **分配携带人、标记已打包**：每件物品可指定携带人并勾选打包状态，表格实时显示
  打包进度。
- **共享物品唯一负责人**：共享物品（如急救包、插线板）全员共用，只能指定一名
  负责人；未指定或负责人被移除时页面会给出提醒。
- **行李箱超重提醒**：每位成员有行李箱预设限重（kg），名下物品总重超出时，
  成员卡片和页面顶部横幅都会提醒超重克数。
- **按人筛选**：可按全部 / 未分配 / 指定成员筛选物品，也可隐藏已打包项。
- **复用历史清单**：以任意历史行程为模板创建新行程，保留成员与物品（含重量、
  共享标记、负责人），打包状态自动重置。
- **打印**：点击"打印"输出按人分组的纸质清单（含勾选框与每人总重），屏幕上的
  操作控件不会出现在打印件中。
- **刷新保留进度**：所有行程、物品、打包状态自动持久化到 localStorage，
  刷新或重开浏览器后原样恢复。

## 环境要求

- Node.js 24.15.x（兼容 Node 20.19+ / 22.12+）
- 仅使用 npm

## 安装

```bash
npm ci        # 或 npm install
```

## 本地启动（开发）

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

浏览器打开 http://127.0.0.1:5173/ 即可。根目录 `run-local.json` 是本地启动清单，
其中的 `{port}` 由启动者替换为实际端口。

## 测试

```bash
npm test      # vitest 单次运行，覆盖重量汇总、超重判定、共享物品负责人约束、
              # 按人筛选、清单复用、建议物品生成与持久化序列化
```

## 构建

```bash
npm run build   # vue-tsc 类型检查 + vite 产物构建（输出到 dist/）
```

## 目录结构

```
src/
  logic.ts        # 纯函数核心逻辑：重量/超重、共享负责人约束、筛选、复用、建议物品、序列化
  store.ts        # 响应式状态 + localStorage 自动持久化
  types.ts        # 数据模型
  App.vue         # 页面骨架：行程切换、提醒横幅、复用与打印入口
  components/     # 新建行程、成员与行李箱、物品表、添加物品、打印视图
tests/
  logic.test.ts   # 核心逻辑单元测试
```
