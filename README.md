# 合住费用分摊本

用 React + TypeScript + Vite 实现的本地记账应用：记录房租、水电、采购等共同账单，
按 **人均 / 固定比例 / 指定金额** 三种方式分摊，自动计算每人的应付、已付与差额，
支持月结、付款备注、修改后重新计算和 CSV 导出。数据只保存在浏览器
localStorage，不接入任何支付服务或外部账号，可完全离线使用。

## 环境要求

- Node.js 24.x（开发时使用 24.15.x 验证）
- 仅使用 npm

## 安装

```bash
npm ci        # 或 npm install
```

## 启动（开发）

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

浏览器打开 http://127.0.0.1:5173/ 即可使用。端口被占用时命令会直接失败，
请换一个空闲端口显式指定。

## 测试

```bash
npm test      # vitest 单次运行，覆盖分摊/月结/CSV 核心逻辑
```

## 构建

```bash
npm run build
```

## 功能说明

- **成员管理**：先添加合住成员；已有账目的成员不可删除，保证历史账可追溯。
- **记账**：标题、分类（房租/水电/采购等）、日期、金额、付款人、分摊方式、备注。
  - 人均：勾选参与成员，余数按成员顺序逐分补齐；
  - 固定比例：为每人填权重，按最大余数法分配零头；
  - 指定金额：为每人填具体金额，合计与账单不一致时拒绝保存。
  - 三种方式都保证分摊总额与账单金额**分毫不差**（金额以“分”为整数存储）。
- **修改与重算**：账单列表中点“修改”，保存后月结差额立即按新数据重新计算。
- **付款记录**：成员间还款可登记金额与备注，自动冲抵当月差额。
- **月结**：按月份查看每人应付/已付/差额，给出结清转账建议；差额全部为零时可
  标记“本月已结清”（可带备注，可撤销）。
- **CSV 导出**：分别导出当月账单、付款记录、月结汇总（UTF-8 带 BOM，Excel 可直接打开）。

## 目录结构

```
src/
  lib/split.ts        分摊算法（人均/比例/指定金额，总额守恒）
  lib/settlement.ts   月结差额与结清建议
  lib/csv.ts          CSV 导出
  lib/money.ts        元 ↔ 分 的解析与格式化
  components/         成员、记账、账单列表、付款记录、月结界面
  store.ts            localStorage 持久化
run-local.json        本地启动清单（web 服务：npm run dev）
```
