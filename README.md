# 餐厅候位叫号台

基于 Vue 3 + TypeScript + Vite 的单页应用，面向餐厅前台的候位、叫号与记录管理。纯前端实现，数据保存在浏览器 localStorage，离线可用，不接入短信或任何外部服务。

## 功能

- **桌型配置**：维护桌型名称、座位数、桌数（默认小桌 2 座 ×4、中桌 4 座 ×6、大桌 8 座 ×2），按座位数升序决定取号前缀（A、B、C……）。
- **登记取号**：录入就餐人数与到店时间，自动按“最小合适桌型”分配号段；人数超过最大桌型会提示；可勾选“接受拼桌”。
- **叫号建议**：某桌型出现空桌时，优先建议“最小合适桌型正好是该桌型”的最早排队者，没有则退到能容纳的最早排队者；无空桌时不给建议。
- **过号 / 取消 / 拼桌**：过号客人可重新排队（排到队尾）；拼桌将多位已叫号客人安排到同一桌并校验座位总数；三类操作均写入当天记录。
- **候位屏**：展示候位组数、预计等待人数、正在叫号、当前候位列表（含到店时间与前方等待组数）及过号客人。
- **清空当天数据**：一键清空候位、号码计数与记录（保留桌型配置），操作本身也会留痕；跨天打开时自动清空候位数据、保留配置。

## 环境

- Node.js 24.15.x（兼容 Vite 7）
- 仅使用 npm

## 安装

```bash
npm install   # 或 npm ci
```

## 启动（开发）

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

浏览器打开 http://127.0.0.1:5173/ 。端口被占用时命令会直接失败，不会自动换端口。

## 测试与构建

```bash
npm test        # Vitest 单次运行核心逻辑测试（取号、叫号建议、过号、取消、拼桌、清空等）
npm run build   # vue-tsc 类型检查 + vite 生产构建
```

## 目录结构

```
src/lib/core.ts        核心领域逻辑（纯函数，全部有测试覆盖）
src/lib/core.test.ts   Vitest 测试
src/lib/store.ts       响应式状态 + localStorage 持久化
src/components/        候位屏、登记取号、叫号台、桌型配置、记录 五个面板
run-local.json         本地启动清单（web 服务即本应用）
```
