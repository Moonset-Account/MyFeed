# 出租房交接检查表

基于 Vue 3 + TypeScript + Vite 的单页应用，用于出租房入住与退租两次交接检查。纯前端实现，数据保存在浏览器 localStorage，离线可用，不接入任何外部账号或收费服务。

## 功能

- **按房间记录**：每个房间记录设施状态（完好 / 磨损 / 损坏 / 缺失）、备注、照片说明（支持上传本地照片或纯文字说明）、钥匙数量、水表与电表读数。
- **两次检查**：入住检查与退租检查分别填写，共用同一套房间与设施模板（可在"入住检查"页增删房间和设施）。
- **逐项对比**：自动对比两次检查，标出状态变化的设施，并计算钥匙差值与水电用量（退租读数 − 入住读数）。
- **完成版交接单门禁**：任一房间的设施状态、钥匙数量、水电表读数未填写，或房东 / 租客签字姓名未录入时，禁止生成完成版交接单，并列出全部缺项。
- **签字与打印**：录入双方签字姓名后生成正式交接单，可一键打印（打印样式已单独适配）。
- **本地 JSON 备份**：一键导出全部数据为 JSON 文件，也可导入备份恢复；平时编辑自动保存到浏览器本地。

## 环境要求

- Node.js 24.15.x（兼容 Node 20.19+ / 22.12+）
- 仅使用 npm

## 安装

```bash
npm install    # 或 npm ci
```

## 启动开发服务

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

然后浏览器打开 http://127.0.0.1:5173/ 。端口被占用时命令会直接失败，不会自动换端口。

## 构建与测试

```bash
npm run build   # vue-tsc 类型检查 + vite 构建，产物在 dist/
npm test        # vitest 单次运行核心逻辑测试（不进入监听模式）
npm run preview # 预览构建产物
```

## 测试说明

核心逻辑（`src/logic.ts`）与界面分离，`src/__tests__/logic.test.ts` 覆盖：

- 缺项（设施状态、钥匙、水电表读数、签字姓名）时禁止生成完成版交接单；
- 两次检查齐备后允许生成；
- 水电用量、钥匙差值计算与设施状态变化标记。

## 数据与隐私

所有数据仅保存在本机浏览器 localStorage 中；导出的 JSON 备份文件由用户自行保管。上传的照片以 dataURL 形式存于本地，不会上传到任何服务器。仓库不提交任何用户数据、媒体文件或运行缓存。

## 目录结构

```
src/
  types.ts                 领域模型类型
  logic.ts                 完整性校验、缺项清单、两次检查对比（纯函数，可测试）
  store.ts                 响应式状态、localStorage 持久化、JSON 导入导出、房间/设施管理
  App.vue                  页头（地址、备份、重置）与四个标签页
  components/
    RoomManager.vue        房间与设施模板管理
    InspectionEditor.vue   入住 / 退租检查编辑（共用一个组件）
    ComparisonView.vue     逐项对比视图
    HandoverDoc.vue        交接单生成门禁、签字录入与打印文档
  __tests__/logic.test.ts  核心逻辑测试
run-local.json             本地启动清单（web 服务：npm run dev）
```
