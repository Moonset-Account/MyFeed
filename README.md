# 捐赠物资分拣台

公益仓库的物资分拣管理应用：登记物资类别、数量、有效期与存放位置，入库时标记质检状态（待检查 / 可发放 / 不合格），发放时校验库存上限并优先提示临期物资，支持按批次追溯与收发记录 CSV 导出。

技术栈：React 18 + TypeScript + Vite，纯前端本地运行，数据保存在浏览器 localStorage，离线可用，不接入任何外部账号或收费服务。

## 环境要求

- Node.js 24.15.x（兼容 24.x）
- 仅使用 npm

## 安装

```bash
npm install
```

## 启动（开发）

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

启动后访问 http://127.0.0.1:5173/ 。端口被占用时 Vite 会直接报错退出（strictPort），请更换端口或释放占用。

## 测试

```bash
npm test
```

使用 Vitest 单次运行核心领域逻辑测试（库存计算、发放上限校验、临期判定与优先排序、入库校验、批次号生成、质检状态流转、CSV 导出），不进入监听模式。

## 构建

```bash
npm run build
npm run preview   # 可选：预览构建产物
```

## 功能说明

- **库存总览**：按类别 / 状态 / 关键字筛选批次，临期（30 天内到期）与已过期批次高亮；待检查批次可在此标记为「可发放」或「不合格」。
- **入库登记**：登记名称、类别、数量、单位、有效期、存放位置、捐赠方与质检状态，自动生成批次号（如 PC20260930-01）。
- **发放出库**：仅「可发放」且有库存的批次可选，按临期优先排序；发放数量不得超过剩余库存，超出会被拦截并提示。
- **批次追溯**：按批次号或物资名称查询，展示该批次入库、质检、发放的全流程记录。
- **收发记录**：入库 / 发放 / 质检流水，支持筛选，并可导出「收发记录」「库存台账」CSV（带 BOM，Excel 可直接打开）。

## 目录结构

```
src/
  lib/domain.ts        核心领域逻辑（纯函数）：库存、发放校验、临期、批次号、CSV
  lib/domain.test.ts   领域逻辑测试
  lib/store.ts         localStorage 持久化与演示种子数据
  components/          库存总览 / 入库登记 / 发放出库 / 批次追溯 / 收发记录
  App.tsx              页面骨架与状态管理
```

页面右上角「恢复演示数据」可清空当前数据并重新载入演示批次。
