# 盘点差异助手

面向小店的离线盘点工具：导入商品清单后录入实盘数量，按货架与类别查看账实差异，记录差异原因并生成复盘表。重复扫码不会悄悄覆盖已录数量，必须人工确认。

## 功能

- **CSV 导入商品清单**：表头支持中文（货号/名称/类别/货架/账面数量）或英文（sku/name/category/shelf/system_qty），兼容带 BOM 的文件；导入失败不会破坏当前盘点数据
- **实盘录入**：扫码枪或手工输入货号 + 数量；同一商品重复录入时返回冲突提示，只有确认后才覆盖
- **差异查看**：按货架或类别分组，显示账面、实盘、净差异与差异项数
- **差异原因**：每个商品可填写原因（如破损、临期、串货），随时修改
- **复盘表**：所有有差异的商品按差异绝对值从大到小排列，可导出 CSV
- **CSV 导出**：盘点明细与复盘表均可导出（带 BOM，Excel 可直接打开中文）
- **样例数据**：页面一键载入 10 个商品的样例清单，可直接试用
- 数据保存在服务进程内存中，不连接任何外部库存系统；重启或"清空重新开始"后数据清零

## 环境准备

需要 macOS 本机 Python 3.11.x，不依赖 Docker、外部账号或收费服务。

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## 启动

```bash
.venv/bin/python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

浏览器打开 http://127.0.0.1:8000/ 即可使用。健康检查接口为 `GET /health`，返回 `{"status": "ok"}`。

## 测试

```bash
.venv/bin/python -m pytest
```

测试覆盖核心逻辑（导入校验、重复扫码保护、差异分组、复盘排序、CSV 导出）与接口行为（健康检查、409 冲突响应）。

## 项目结构

- `app.py` — FastAPI 入口，同一进程提供页面与 `/api/*` 业务接口
- `stocktake.py` — 纯 Python 核心业务逻辑，可独立测试
- `static/` — 原生 JavaScript 单页界面（无构建步骤、无 npm）
- `sample_data/products_sample.csv` — 样例商品清单
- `tests/` — pytest 测试
- `run-local.json` — 本地启动清单

## CSV 格式

导入示例：

```csv
货号,名称,类别,货架,账面数量
A001,可口可乐330ml,饮料,A架,24
```

导出（盘点明细 / 复盘表）列：货号、名称、类别、货架、账面数量、实盘数量、差异、差异原因。
