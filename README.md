# 阳台植物养护日历

一个纯本地运行的 Svelte + TypeScript + Vite 单页应用，帮助记录阳台植物的养护节奏。

## 功能

- **植物档案**：每盆植物记录名称、品种、浇水间隔、光照位置（全日照 / 半日照 / 散射光 / 耐阴）和可选的施肥周期；照片以占位图标代替（离线演示不接入外部图床）。
- **待办生成**：根据「上次实际养护日期 + 间隔」自动计算下次浇水 / 施肥到期日，首页提醒列表按紧迫程度排序（逾期 → 今天 → 未来 7 天）。
- **阴雨顺延**：连续阴雨时可手动顺延浇水 1–7 天。顺延只新增顺延记录、推迟到期日，**不会**写入浇水事件，待办保持挂起并标注「已顺延 N 天（未完成）」；实际浇水后旧顺延自动失效。
- **养护记录**：浇水、施肥、换盆分别按实际日期记录，详情页可查看时间线并删除误录条目。
- **本地提醒**：全部数据保存在浏览器 localStorage，无需联网与账号。
- **备份恢复**：一键导出 JSON 备份文件；导入时校验文件格式与字段，拒绝损坏或非本应用的文件。

## 环境要求

- Node.js 24.15.x（兼容 24.x）
- 仅使用 npm

## 安装

```bash
npm install   # 或 npm ci
```

## 启动（开发）

```bash
npm run dev
# 或按 run-local.json 指定端口：
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

浏览器打开终端提示的地址（默认 http://127.0.0.1:5173/ ）。演示完全离线可用。

## 构建与测试

```bash
npm run build   # 产出 dist/
npm test        # vitest 单次运行核心逻辑测试（到期计算、顺延语义、备份校验）
npm run check   # svelte-check 类型检查（可选）
```

## 数据与隐私

所有数据仅存于本机浏览器 localStorage（键 `balcony-plant-calendar-v1`），不接入外部账号或收费服务；备份文件由用户自行保存，仓库不包含任何运行数据。
