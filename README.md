# 入职任务地图

面向新成员的入职事项自助跟进工具。按角色预置账号申请、设备领取、权限开通、培训、实践任务等事项及负责人，新人可以在依赖地图上看到事项的先后顺序与完成状态；前置事项未完成时会提醒并阻止误标完成，逾期事项集中显示在页面顶部。

所有数据均为本地示例数据，进度保存在浏览器 localStorage，不接入企业账号或任何外部服务，离线可用。

## 功能

- 示例角色：前端工程师、产品经理、运营专员，各含完整任务模板（负责人、备注、期限、前置依赖）
- 任务地图：按依赖深度分列的 SVG 依赖图，实线表示前置已完成、虚线表示前置未完成
- 状态总览：可进行 / 待前置 / 已逾期 / 已完成，含进度条
- 阻塞提醒：前置未完成时任务置灰不可完成，并列出缺失的前置事项
- 逾期面板：逾期项集中显示，点击可定位到任务详情
- 本地持久化：按角色分别保存入职日期与完成记录，可一键重置

## 环境要求

- Node.js 24.15.x（兼容 20+），仅使用 npm

## 安装

```bash
npm ci        # 或 npm install
```

## 启动

```bash
npm run dev -- --hostname 127.0.0.1 --port 3000
```

`npm run dev` 会先执行生产构建再以前台服务启动（保证端口被占用时直接失败退出、首屏即可访问），浏览器打开 http://127.0.0.1:3000/ 即可使用。

日常开发需要热更新时可用：

```bash
npm run dev:hmr -- --hostname 127.0.0.1 --port 3000
```

也可以分开执行生产构建与启动：

```bash
npm run build
npm start
```

## 测试

```bash
npm test
```

使用 vitest 单次运行，覆盖核心逻辑（任务状态推导、依赖分层、逾期判定、进度统计、示例数据完整性），测试位于 `tests/onboarding.test.ts`。

## 目录结构

- `src/lib/types.ts` — 角色、任务、进度等类型定义
- `src/lib/roles.ts` — 示例角色与任务模板数据
- `src/lib/onboarding.ts` — 状态推导、依赖分层、逾期与进度统计等纯逻辑
- `src/lib/storage.ts` — localStorage 读写
- `src/app/page.tsx` — 页面组装与交互
- `src/components/` — 任务地图、任务详情、逾期面板组件
- `run-local.json` — 本地启动清单
