# 家具组装步骤卡

React + TypeScript + Vite 实现的家具组装引导应用。管理员按顺序配置零件、工具、示意图和检查点；用户逐步勾选完成。示例数据为虚构产品「云梯·三层书架 YT-300」。

## 功能

- **管理员配置**：在「管理配置」页维护方案名称、零件表、工具表，以及按顺序排列的步骤（标题、说明、示意图、关联零件/工具、检查点，检查点可标记为必需）。配置保存在浏览器 localStorage，可一键恢复默认方案。
- **逐步组装**：步骤卡展示说明、示意图、本步零件与工具；勾选检查点后点击「完成本步」推进。
- **必需检查点拦截**：跳过必需检查点直接完成时会被拒绝并弹出提示。
- **缺件暂停与补件清单**：发现缺件可登记缺失零件与数量，组装进入暂停状态并生成补件清单（可打印/复制）；补件到达后一键恢复。
- **进度恢复**：进度实时写入 localStorage，刷新或重开浏览器自动恢复到上次位置，并显示恢复提示。
- **步骤搜索**：按步骤标题、说明、零件名、工具名过滤，点击结果直接跳转。
- **可打印材料表**：点击「打印材料表」输出零件清单、工具清单及（如有）补件清单的打印版式。

## 环境要求

- Node.js 24.15.x（兼容 20.19+ / 22.12+）
- 仅使用 npm；安装依赖需要联网，运行与演示完全离线，无外部账号或收费服务。

## 安装与启动

```bash
npm install        # 或 npm ci
npm run dev        # 开发模式，默认 http://127.0.0.1:5173
```

按 run-local.json 启动（指定端口、绑定本机、占用即失败）：

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

## 构建与测试

```bash
npm run build      # 类型检查 + 产物构建（dist/）
npm test           # vitest 单次运行核心逻辑测试
npm run preview    # 预览构建产物
```

测试覆盖：必需检查点拦截、进度推进与完成判定、缺件暂停/恢复、补件清单生成（非法项过滤、数量封顶）、步骤搜索、进度序列化与损坏数据回退。

## 目录结构

```
src/
  lib/types.ts        数据模型（方案、步骤、检查点、进度）
  lib/assembly.ts     纯逻辑：拦截、搜索、补件清单、进度序列化
  lib/assembly.test.ts 核心逻辑测试
  state/reducer.ts    进度状态迁移（纯函数）
  data/defaultPlan.ts 示例方案：虚构书架 YT-300
  components/         步骤卡、导航搜索、缺件弹窗、管理配置、打印材料表、SVG 示意图
  App.tsx             组装主流程与 localStorage 持久化
```

所有示意图均为内联 SVG，不请求任何外部资源。
