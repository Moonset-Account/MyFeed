# 宴席座位安排图

用 Svelte + TypeScript + Vite 实现的本地宴席排位工具。设置桌数与座位数、维护宾客名单，把宾客拖到座位入座，登记“同行 / 需避开”关系和无障碍座位需求；超员与各类冲突会即时标红提示。支持按桌打印席位表与未安排名单、撤销上一步操作。所有数据只保存在浏览器 localStorage，不联网、不上传。

## 功能

- **宴席设置**：桌数、每桌座位数、每桌无障碍座位数（每桌编号靠前的座位为无障碍座位，标记 ♿）；缩小规模时被裁掉的宾客自动回到未安排名单。
- **宾客名单**：添加 / 删除 / 改名，标记“需无障碍座位”；未安排与已入座分组展示。
- **拖拽入座**：把宾客从名单拖到座位；拖动已入座宾客可换座，拖回“未安排”区域取消入座；座位被占用时拒绝并提示。也可以在“宾客详情”里用下拉框直接安排到空位。
- **关系登记**：在“宾客详情”中为任意两位宾客勾选“同行”或“需避开”（两者互斥，对称生效）。
- **即时冲突提示**：超员（宾客数 > 总座位数）、需避开者同桌、同行者被分桌（含传递成组）、需无障碍座位者坐到普通座位，都会在右侧面板列出，相关座位与餐桌即时标红。
- **打印**：可按“全部餐桌”或指定某桌打印席位表，可选附未安排名单；打印件含空位、无障碍标记与各桌冲突提示。
- **撤销**：工具栏“撤销上一步”或 Ctrl/⌘+Z，可连续撤销；历史同样保存在本地，刷新后仍可撤销。
- **纯本地存储**：状态与撤销历史保存在 localStorage（键 `banquet-seating:*`），无任何网络请求。

## 环境要求

- Node.js 24.15.x（兼容 ^20.19 / >=22.12 均可），仅使用 npm。

## 安装

```bash
npm install    # 或 npm ci（已提交 package-lock.json）
```

## 启动（开发）

```bash
npm run dev
# 或按 run-local.json 清单指定地址与端口：
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

启动后访问 http://127.0.0.1:5173/ 。服务前台运行、绑定 127.0.0.1；端口被占用时按 `--strictPort` 直接失败，不会自动换端口。

## 测试与检查

```bash
npm test        # vitest 单次运行核心逻辑测试（座位、关系、冲突、撤销、持久化）
npm run check   # svelte-check 类型检查
npm run build   # 产物输出到 dist/
```

## 使用流程

1. 在“宴席设置”中填桌数、每桌座位数、每桌无障碍座位数。
2. 在“宾客名单”中逐个添加宾客，需要无障碍座位的勾上对应选项。
3. 把宾客拖到空座位入座；点击任意宾客，在“宾客详情”中登记同行 / 需避开关系。
4. 右侧“冲突提示”实时显示超员与各类冲突，调整座位直至无冲突。
5. 在顶部选择打印范围，点击“打印席位表”。

## 目录结构

```
src/
  lib/
    types.ts        数据模型（宾客 / 餐桌 / 座位 / 冲突）
    seating.ts      纯函数核心逻辑：入座、关系、冲突检测、统计
    store.ts        Svelte store：commit/undo、localStorage 持久化、页面操作
    *.test.ts       核心逻辑与存储测试（vitest）
  components/       设置、名单、座位图、详情、冲突、打印等组件
  App.svelte        页面骨架与工具栏
run-local.json      本地启动清单（web 服务：npm run dev）
```
