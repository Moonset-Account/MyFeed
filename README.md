# 宴席座位安排图

基于 Svelte + TypeScript + Vite 的本地单机应用：设置桌数与座位数，维护宾客名单，拖动宾客入座，并记录同行、需避开关系与无障碍座位需求。超员与各类冲突即时提示，支持按桌打印席位表、查看未安排名单、撤销上一步操作。所有数据仅保存在浏览器 localStorage，不接入任何外部服务。

## 环境要求

- Node.js 24.15.x（与本机运行时一致）
- 仅使用 npm

## 安装

```bash
npm install   # 或 npm ci
```

## 启动（开发）

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

浏览器打开 http://127.0.0.1:5173/ 即可使用。根目录 `run-local.json` 中的启动清单使用同一命令，`{port}` 由启动者替换为实际端口。

## 测试与检查

```bash
npm test        # Vitest 单次运行核心逻辑测试（冲突判定、入座/撤销等）
npm run check   # svelte-check 类型检查
npm run build   # 生产构建到 dist/
```

## 功能说明

- **宴席设置**：桌数、每桌座位数、每桌无障碍座位数。缩小规模不会删除安排，超出的宾客标记为“超员”。
- **宾客名单**：添加/删除宾客；每位宾客可勾选“需要无障碍座位”，并设置同行、需避开关系（关系判定双向生效）。
- **拖动入座**：把宾客从名单拖到桌位即可入座；拖到已占用座位会替换原宾客；拖回“未安排名单”或在座位芯片上双击可取消安排。
- **即时冲突提示**：超员、需避开者同席、同行者未同席、无障碍需求未满足，都会在顶部冲突栏与对应桌卡上即时显示。
- **打印**：点击“打印席位表”生成按桌排列的席位表，附未安排名单与待处理冲突。
- **撤销**：顶栏“撤销上一步”可逐步回退最近的任意操作（最多保留 100 步）。
- **本地存储**：所有数据保存在浏览器 localStorage（键 `banquet-seating-v1`），不上传、不联网。

## 目录结构

```
src/
  lib/
    types.ts       数据模型（宾客、设置、座位、应用状态）
    rules.ts       纯函数规则：超员/避开/同行/无障碍冲突判定
    store.ts       Svelte store：状态、历史撤销、localStorage 持久化
    dnd.ts         拖拽中的宾客 id
    rules.test.ts  规则测试
    store.test.ts  状态与撤销测试
  components/      设置、宾客、桌位、打印视图组件
  App.svelte       页面骨架与冲突汇总
```
